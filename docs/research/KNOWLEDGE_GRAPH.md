# gfx1200 SWMMAC 优化项目 — 知识图谱

**总纲**: 以消费级显卡 Radeon RX 9060 XT (RDNA4) 为载体, 通过电磁近场测量、N14量子钟绝对时基、指令级微架构逆向、汇编调度与持久化内核设计, 实现从量子隧穿到计算吞吐的全栈物理-性能联合优化与验证。

---

## 卷壹 · 电磁指纹与工艺物理

### 第1章 近场电磁测量基础

- 硬件: 40元磁环天线 + RSP1 SDR + Zero-IF 模式
- 采样: 10/15 MSPS, IQ miri 12-bit, BW 5-8 MHz
- 测量对象: GPU VRM 区域近场 H 场 (供电电感/DrMOS 上方)

**双 GPU 对比**:

| 指标 | GTX 1060 (16nm) | gfx1200 (4nm) |
|------|-----------------|---------------|
| VRM DCM 基频 | 37.2 Hz | 57.0 Hz |
| SMPS 频率 | 50.9 kHz | 51.05 kHz |
| SMPS SNR | 27× | 43× |
| DrMOS t_r | <490 ns | <42 ns |

### 第2章 工艺指纹解析

- 4nm 栅氧 ~0.8 nm (≈5 原子层), 量子隧穿漏电 10-100× 于 16nm
- DCM 频率比 57.0/37.2 = 1.53× — 编码了隧穿漏电流的补偿需求
- 4nm DrMOS 集成化 → di/dt 更高 → SMPS 43× SNR

## 卷贰 · 绝对时基与 N14 量子钟

- N14 参考: 9,374,984 Hz (NQR 超精细跃迁, 绝对物理常数)
- SMPS 锚频: 51,050 Hz, 晶振锁定, 实测 51049.951 Hz (0.96 PPM)
- N14:GPU 比率: 1:336 (1 GPU cycle = 336 N14 cycles)
- PLL 长期积分精度: 0.33 PPM (120s, 18 亿样本)
- 锁相环 BW=0.5 Hz, Q≈1253, 相干时间 23 ms

## 卷叁 · 指令微架构与 SWMMAC 极限吞吐

### XDL 矩阵管线

- SWMMAC 执行延迟: 16 cycles (LLVM SISchedule.td 确认)
- HWXDL 独立管线 (`SQ_INSTS_VALU=0`, `SQ_WAVE_CYCLES=0`)
- VGPR 实测: 136 (估算 139, 误差 2%)

### 26-cycle 有效管线模型

| 参数 | 值 | 来源 |
|------|-----|------|
| SWMMAC 执行 | 16 cycles | LLVM SchedWrite |
| VGPR 读/写 + 波切换 | ~10 cycles | 硬件计数器反推 |
| **有效管线** | **26 cycles** | 模型+实测 |
| 波槽/SIMD | 16 | RDNA4 硬件 |
| 同步 IPC | 0.615 | 16/26 |
| L2 持久化 IPC | 0.744 | ×1.21 |

### 性能演进

## 卷肆 · 软件流水线与持久化内核

### 波同步根因

- 传统 blockIdx.x 同步 → 所有 wave 锁步 → VGPR 读端口争用
- 解决方案: atomicAdd 波散布 + L2 持久化计数器
- hipMemset 消除 → 吞吐 +21%

### rocWMMA 集成

- `StaggeredPipeline` 入库 (原子散布 + wrap-counter + 26-cycle 模型)
- `ChainPipeline` 标记 deprecated
- 5 文件部署至 `/opt/rocm/include/rocwmma/`

## 卷伍 · 数字锁相环与相位噪声分析

### 方法演进

FFT (失败, SNR 不足) → N14 DPLL 长期积分 → C 流式实现

### EMI 分离

- 差值 PSD + 频段缩放因子 k
- 未屏蔽 k=1.14, 屏蔽后 k=1.35
- 纯净 VRM 相位噪声负载下降 67.6%

### 物理屏蔽验证

- 屏蔽布隔离后, 负载原始数据已低于空载
- 0.1-0.5 Hz: 负载 33.7 ns vs 空载 35.2 ns

## 卷陆 · N14 守护进程与实时反馈

### QTF (量子隧穿因子)

- 定义: 0.1-0.5 Hz 纯净相位噪声 RMS (ns)
- 空载: ~35 ns, 负载极限: ~11 ns
- 警戒 >30 ns, 异常 >50 ns

### 实现

- `n14_daemon.c`: C 流式 DPLL + 共享内存输出
- 每 10 秒更新 `/n14_smps_fingerprint`
- HIP 端 3 行 mmap 读取

## 卷柒 · 方法论总结

### 全栈闭环

```
量子输运:     4nm 栅氧隧穿 → DCM 57.0 Hz
供电控制:     SMPS 51050 Hz @ 0.33 PPM
供电噪声:     QTF 0.1-0.5 Hz 11.4 ns (负载)
微架构:       26-cycle 有效管线, IPC 0.744
计算吞吐:     4326 TOPs (74.2%), +462% vs 基线
```

### 七步法

1. 物理指纹采集 (SDR + 磁环)
2. 绝对时间基准 (N14 量子钟)
3. 微架构逆向 (微基准 + LLVM + PMU)
4. 指令级调优 (汇编 + 寄存器预算)
5. 持久化内核 (消除启动/重置开销)
6. 电磁-计算闭环 (物理验证优化效果)
7. 运行时反馈 (守护进程 + 自适应调度)
